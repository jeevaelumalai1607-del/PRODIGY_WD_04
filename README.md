# 💼 Personal Portfolio Website

## 📌 Overview

This project is a **Personal Portfolio Website** developed using **HTML** (with embedded CSS). It is designed to showcase personal information, technical skills, projects, and contact details in a clean and responsive layout.

This project was completed as **Task-04** of the **Prodigy InfoTech Web Development Internship**.

---

## 🚀 Features

- 👤 Professional Home Section
- 📝 About Me
- 💡 Skills Section
- 💼 Projects Showcase
- 📞 Contact Information
- 📱 Responsive Design
- 🎨 Modern and Clean User Interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Embedded in HTML)

---

Portfolio/

---

## ▶️ How to Run

1. Download or clone the project.
2. Open the project folder in **Visual Studio Code**.
3. Open the `index.html` file.
4. Right-click and select **Open with Live Server**, or simply open `index.html` in your web browser.
5. Explore the portfolio website.
